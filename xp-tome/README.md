# aaai-xp-tome (optional Java resource pack)

Makes a book carrying `custom_model_data` string `xp_tome` (the XP Tome from AAAI-Original-Enchantment) look purple. Every other book is unchanged. Texture from bl4ckscor3/XP-Tome (MIT, see LICENSE-XP-Tome.txt).
Zip the folder contents (no top-level folder, without this README) to `deploy/resourcepacks/aaai-xp-tome.zip`; AAAIResourcePacks needs the sha1 of that zip.
