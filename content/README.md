# AAAI Content pack

Optional textures (original pixel art made for this server) for: Skill XP Bottles 1k-500k (experience_bottle), Seeker Eye (ender_eye), Route Fragment + Heavy Core Fragment (echo_shard), Disarm Slime (slime_ball), Immortal Heart (totem_of_undying), Elytra Fragment (phantom_membrane), Salty Bedrock (bedrock, cube model). Items are selected by custom_model_data string = aaai:item_id; without the pack they look vanilla.

Note: `items/echo_shard.json` also keeps the `reinforced_echo_shard` case of the advanced-netherite pack (Java packs do not merge item definitions), so this pack must load AFTER advanced-netherite.
