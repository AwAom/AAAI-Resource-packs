# aaai-tome (optional Java resource pack)

Restyles the books of AAAI-Original-Tome: a `minecraft:book` carrying `custom_model_data` string `xp_tome` (XP Tome, purple, texture from bl4ckscor3/XP-Tome, MIT, see LICENSE-XP-Tome.txt) or `ancient_tome` (Ancient Tome, original art by AAAI, `docs/design/ancient-tome/make_texture.py`). Every other book is unchanged.
Zip the folder contents (no top-level folder, without this README) to `deploy/resourcepacks/aaai-tome.zip`; AAAIResourcePacks needs the sha1 of that zip. Replaces the old `xp-tome` pack (release xp-tome-1.0.0 stays online until the new one is released).
