# aaai-tome (optional Java resource pack)

Restyles the books of AAAI-Original-Tome: a `minecraft:book` carrying `custom_model_data` string `xp_tome` (XP Tome, purple, texture from bl4ckscor3/XP-Tome, MIT, see LICENSE-XP-Tome.txt) or `ancient_tome` (Ancient Tome, original art by AAAI, `docs/design/ancient-tome/make_texture.py`). Every other book is unchanged. The 6 bundle items (`ancient_tome_bundle_1..6`, grades E-S) use the same book base: 32x32 icons of a leather pouch with a violet tome, ribbon and letter in the grade colour; original art by AAAI, drawn by `docs/design/ancient-tome/make_bundle_textures.py` (no third-party material).
Zip the folder contents (no top-level folder, without this README) to `deploy/resourcepacks/aaai-tome.zip`; AAAIResourcePacks needs the sha1 of that zip. Replaces the old `xp-tome` pack (release xp-tome-1.0.0 stays online until the new one is released).
