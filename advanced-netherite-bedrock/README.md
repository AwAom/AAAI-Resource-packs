# advanced-netherite-bedrock

Native Bedrock pack (`pack/` -> `.mcpack`) + Geyser custom item mapping (`geyser/`) for AAAI-RM-AdvanceNetherite. Covers ingots, blocks, swords, mining tools (with the tier's mining speed) and armor (custom items + attachables for the worn model, from the mod's 64x32 textures; **armor is untested on a real Bedrock client**). **Not covered (stays vanilla netherite on Bedrock):** spears.
Install: `.mcpack` -> `plugins/Geyser-Spigot/packs/`, mapping -> `plugins/Geyser-Spigot/custom_mappings/`, restart, log must say `Registered N custom items`. Textures: Autovw/AdvancedNetherite, GPL-3.0 (this folder only).
