# advanced-netherite (optional Java resource pack)

Textures, models and armor assets of Advanced Netherite by Autovw (GPL-3.0, https://github.com/Autovw/AdvancedNetherite), wired to the server plugin AAAI-RM-AdvanceNetherite through `custom_model_data` strings (`netherite_<tier>_<kind>`). The 12 files in `assets/minecraft/items/` fall back to the normal vanilla netherite look for every other item. Armor worn on the body keeps the vanilla netherite model unless the server sets `armor-model: pack`.
