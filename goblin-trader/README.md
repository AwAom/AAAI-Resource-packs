# aaai-goblin-trader (optional Java resource pack)

Gives the server's goblin traders (AAAI-3Party-GoblinTrader) a 3D head: a green goblin head with pointed ears for the Goblin Trader and a red horned head for the Vein Goblin Trader.
The pack only changes moss / nether wart blocks that carry `custom_model_data` `goblin_trader_head` / `vein_goblin_trader_head`; natural wandering traders and every other block look vanilla.
Original art (MIT). The idea and trade table come from "Goblin Traders" by MrCrayfish (MIT), no assets of that mod are used (see `CREDITS.txt`).
Zip the folder contents (no top-level folder, without this README) as `aaai-goblin-trader-<version>.zip`; AAAIResourcePacks needs the sha1 of that zip.
