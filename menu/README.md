# AAAI-Menu pack

Optional flat icons for the AAAI menus (main menu first). Menu buttons keep a vanilla base item (ender pearl, door, hopper...) and
add `custom_model_data` = `menu_<name>`; with this pack the button shows a clear coloured icon, without it the vanilla item.
Real items of those kinds are untouched (the pack only reacts to the `menu_*` strings).

All art is original, drawn by `../resourcepack-src/gen_icons.py` (no third-party content). Edit the script and re-run to change icons.

`menu_reward_hidden` (wooden crate with a "?", on a barrel base) is the hidden loot slot of the dungeon reward UI (AAAI-Original-Dungeon).
