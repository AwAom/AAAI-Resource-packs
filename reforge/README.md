# AAAI Reforge (Java) 1.6.2

Textures for the Reforge stones, Add Slot, Re Slot, stat stones, universal stones and the ghost slot icons. All art is original (AAAI / AwAom).

Every item has its own `assets/aaai/items/<item_id>.json` (item_model `aaai:<item_id>`, never overwritten by other packs). The legacy custom_model_data cases are kept in `assets/minecraft/items/` for copper_ingot, iron_ingot, gold_ingot, netherite_ingot (stones 1-4), echo_shard (universal stones), resin_brick (Add Slot), amethyst_shard (Re Slot), prismarine_shard (stat stones), heart_of_the_sea (bundle) and gray_dye (ghost icons). Put this pack lowest in the pack order: on shared bases the other packs' files win, which is intended.
