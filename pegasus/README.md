# aaai-pegasus (optional Java resource pack)

Gives the server's Pegasus mount (AAAI-Original-Mob, `/aaaiob mount`) its look: a pearl coat with an aurora mane and tail
on the vanilla horse (a worn body-armor equipment asset `aaaimob:pegasus_coat`) and a premium saddle (`aaaimob:pegasus_saddle`).
Other horses are unchanged. Wings and animation come from the optional client mod; players without it see the coat horse.

The coat is an adaptation of "Pegasus" by DibArts, **CC BY 4.0** (see `LICENSE-Pegasus-DibArts.txt`, `CREDITS.txt`); the saddle is original (MIT).
Zip the folder contents (no top-level folder, without this README) as `aaai-pegasus-<version>.zip`; AAAIResourcePacks needs the sha1 of that zip.
